# Project 01: Rate Cuts and Banking Sector Returns

Testing whether central bank rate cuts are bullish for bank stocks.

- India: RBI → Nifty Bank (2013-2025, n=17)
- US: Fed → XLF Financials (2000-2025, n=31) and KBE Pure Banks (2005-2025, n=18)

Finding: No statistical support for the narrative in either market.
